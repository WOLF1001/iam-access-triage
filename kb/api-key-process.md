# Як отримати API-ключ до AI-моделі

Ця стаття пояснює, як отримати ключ для автоматизації (дубляж, локалізація, аналітика) так, щоб він не став витоком.

## Що написати в IAM-канал

1. **Модель / провайдер:** Claude API, Gemini API тощо.
2. **Команда й задача:** для чого саме ключ.
3. **Власник ключа:** хто відповідає за нього й за витрати.
4. **Місячний ліміт витрат:** приблизна сума.

Без цих чотирьох пунктів бот спершу поставить питання й лише потім надішле запит на апрув.

## Що відбувається далі

1. Апрув ліда й власника AI-платформи (кнопка в Slack).
2. Ключ створюється в **проєкті / workspace команди** з лімітом витрат і обмеженнями (лише потрібні API).
3. Ключ кладуть у **1Password-vault команди**. Ти отримуєш доступ до запису, а не сам ключ у повідомленні.

## Чого не робити ніколи

- **Не надсилай ключ у Slack, тікет чи код.** Якщо надіслав — це вже витік, див. нижче.
- Не використовуй один ключ на кілька команд: неможливо зрозуміти, хто витрачає.

## Ключ злитий або «здається, злитий»

Пиши в IAM-канал одразу. Видалити запис в 1Password **недостатньо**: ключ треба відкликати в провайдера й видати новий. Цим займається security, пріоритет найвищий.
