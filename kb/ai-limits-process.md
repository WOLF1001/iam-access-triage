# Як підняти ліміти, отримати seat або extra usage в AI-тулах?

Коротко: **ліміт = гроші**, тому його погоджують лід і власник бюджету. Напиши, кому, скільки, навіщо і на який строк — і запит піде на апрув одним колом.

## Що написати

- **Хто:** список корпоративних email, а не «5 людей з команди, список дам».
- **Що:** вищий seat, extra usage чи ліміт API.
- **Навіщо:** проєкт або задача.
- **На який строк:** постійно чи до певної дати.

## Часті ситуації

| Ситуація | Що відбувається |
|---|---|
| «У колеги ліміт не закінчується, а в мене так» | частіше за все у вас різні seat-и або різні проєкти / workspace. Напиши — бот перевірить, який у тебе seat |
| «Закінчились кредити, все стоїть» | це питання бюджету: запит іде власнику бюджету з пріоритетом, але без апруву не поповнюється |
| Спільний командний акаунт | ліміт не піднімаємо — спільний акаунт = немає персонального аудиту. Запропонуємо персональні seat-и |
| Підключити конектор / MCP до Claude | окремий security review: конектор дає моделі доступ до даних іншої системи |

## Чого бот не зробить

Не підніме ліміт і не поповнить баланс сам — лише підготує запит апруверам. Не підключить картку для оплати: це finance.
